# Session archive

`omp-archive-wmp-visualizer-re.zip` was produced with
[omp-archive](https://github.com/alosslessdev/omp-archive-main) for the
research session that produced this dossier.

| Field | Value |
|---|---|
| Format | `omp-session-archive/v1` |
| Session | `01a16c03-af2c-76e9-b2b8-8e301d4d8da6` |
| Title | 🎛️ VIS: Document Windows 7 music visualizer effects |
| Entries | 768 transcript entries |
| Tool logs | 14 files, including the full 4.3 MB download log |

## What is inside

* `session.jsonl` — the main transcript, verbatim.
* `artifacts/` — every tool/background-job log, untruncated.
* `agents.json`, `jobs.json` — runtime state captured at archive time.
* `viewer.html` — standalone viewer with the whole conversation.
* `manifest.json` — index with sizes and counts.

## Redaction

The only change from the raw export is that the local Windows user path was
replaced with `<user>` (`C:\Users\<user>`, and the account name in Ghidra
project metadata). Everything else is byte-for-byte as exported.

## Caution

The archive is otherwise unredacted: it contains local paths, command output,
and short excerpts of decompiled code used as evidence. Review before
mirroring. No Microsoft binaries are included.
